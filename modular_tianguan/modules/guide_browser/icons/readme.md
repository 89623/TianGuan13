# 图标目录（左上角「指南浏览器」按钮）

把 **.dmi** 丢进这个文件夹，左上角那个按钮就会渲染成这张图 —— 不用改代码、不用重新编译。

规则（见 `../code/guide_config.dm` 的 `tianguan_guide_load_button_icon()`）：

- 目录里有多个 dmi 时，取**文件名排序后的第一个**；所以正式只放**一个**。
- 用该 dmi 的**第一个 icon_state**（state 叫什么名字无所谓）。
- 建议 **32×32**（HUD 图标标准尺寸）；别的尺寸也能显示，但可能被拉伸。
- 目录为空 / 文件读不出来 ⇒ **自动回退**到上游内置图标（`icons/hud/actions.dmi` 的 `round_end`），
  只记一行日志，不报错、不影响开服。
- 生效时机：**服务启动**时扫一次；之后换了 dmi，用游戏内管理员指令「重载指南浏览器配置」当场生效
  （它会顺带重扫本目录，并把结果写进日志）。
- 自证日志：启动日志里会有一行
  `GUIDE_BROWSER: 左上角按钮图标 → <路径>（state xxx，共 N 个）`；没找到则是 `…用内置图标`。

> ⚠ 这个目录里只放**正式要用的** dmi。开发时临时丢进来的测试图（例如纯色方块）**提交前记得删掉** ——
> 它会被当成按钮图标生效。
